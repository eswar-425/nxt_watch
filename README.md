# 🎥 Nxt Watch

Nxt Watch is a **YouTube-inspired video streaming web application** built using **React.js**. It provides users with a seamless video streaming experience through secure authentication, categorized video browsing, search functionality, video playback, and personalized saved videos. The application follows a responsive design and supports both **Light** and **Dark** themes.

# ✨ Application Features

### 🔐 Authentication

- Secure login using JWT Authentication
- Protected routes for authenticated users
- Persistent login using Cookies
- Automatic redirection for unauthorized users

### 🏠 Home

- Fetches videos using REST APIs
- Search functionality
- Loading indicator
- Retry on failure
- No search results view

### 🔥 Trending

- Displays trending videos
- API integration
- Retry functionality

### 🎮 Gaming

- Displays gaming videos
- Responsive video cards

### 🎥 Video Details

- Video playback using React Player
- Like & Dislike functionality
- Save & Unsave videos
- Displays channel details and video information

### 💾 Saved Videos

- Save favorite videos
- Remove saved videos
- Empty state when no videos are available

### 🌙 Theme

- Toggle between Light and Dark themes
- Theme managed globally using Context API

# 🌐 REST APIs

| API | Method | Description |
|------|--------|-------------|
| Login API | POST | User Authentication |
| Home Videos API | GET | Fetch Home Videos |
| Trending Videos API | GET | Fetch Trending Videos |
| Gaming Videos API | GET | Fetch Gaming Videos |
| Video Details API | GET | Fetch Video Details |

# 💻 Installation

### Clone the Repository

```bash
git clone https://github.com/eswar-425/nxt_watch.git
```

### Navigate to the Project

```bash
cd nxt_watch
```

### Install Dependencies

```bash
npm install
```

### Run the Application

```bash
npm start
```

The application will start on:

```text
http://localhost:3000
```
