# Nxt Watch

A responsive YouTube-inspired video streaming web application built with React.js. The application provides secure authentication, video browsing, search, trending, gaming, saved videos, dark/light themes, and video playback.

## Features

- JWT Authentication
- Protected Routes
- Home, Trending, Gaming and Saved Videos
- Video Details with React Player
- Like, Dislike and Save functionality
- Search Videos
- Dark and Light Theme
- Responsive Design
- REST API Integration
- Loading, Failure and Retry States

## Tech Stack

- React.js
- React Router
- Context API
- Styled Components
- REST APIs
- JWT Authentication
- React Player
- js-cookie
- date-fns
